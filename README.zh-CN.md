# ENM 入门课程：中文提纲

> 这是 [乔慧捷老师原课程](https://github.com/qiaohj/ENM_curriculum)英文提纲的中文对照版本，由本 fork 维护者整理；[英文原文](README.md)与 D1–D15 原始代码均保留。以下各日条目介绍课程提纲所列内容，不表示仓库附带全部数据，也不表示每项演示都已完成独立复现。我们另写的理解与提醒集中在[学习导航](docs/学习导航.md)、[方法理解](docs/方法理解.md)和[来源与致谢](docs/来源与致谢.md)。原课程代码遵循仓库内的 [MIT 许可](LICENSE)。

## Day 0｜装好工具，备齐课程材料

1. **统计与地理工具。** 安装 R（≥ 4.3）和 RStudio Desktop，也可以使用带 R 扩展的 VS Code；安装与系统架构匹配的 JDK 11/17/21，供 `rJava` 和独立版 MaxEnt 使用；用 QGIS 长期支持版查看矢量和栅格；安装 Git 与 Fork/GitHub Desktop 等客户端；将独立版 `maxent.jar`（3.4.4 或更新）放到合适的 R 库路径。
2. **取得代码并安排目录。** 克隆[原课程仓库](https://github.com/qiaohj/ENM_curriculum)，准备 `Data/`、`Figures/`、`Scripts/`、`Output/` 等目录。
3. **安装 R 包。** 空间处理用 `terra`、`sf`、`geodata`、`rnaturalearth`、`rnaturalearthdata`、`units`；整理和作图用 `data.table`、`ggplot2`、`patchwork`、`ggrepel`、`viridis`；建模用 `ENMeval`、`biomod2`、`dismo`、`maxnet`、`mgcv`、`randomForest`、`ecospat`。运行 `rJava::.jinit()` 检查 Java 接口。
4. **准备数据。** 取得 WorldClim v2.1 的 19 个生物气候变量，提纲列出 10′、5′ 和 30″ 三档分辨率；另备数字高程、土地覆盖、全球陆地底图，以及 GBIF 物种记录和 IUCN 专家范围图。英文提纲中的 Figshare DOI `10.6084/m9.figshare.XXXXXXX` 是占位符，不能当作数据下载地址。
5. **检查环境。** 用诊断脚本确认 GDAL、GEOS、PROJ 和 Java 能被正常调用。

## Day 1｜从记录到第一张适宜性图

1. 从 GBIF 取得丹顶鹤（*Grus japonensis*）出现记录。
2. 从 [WorldClim](https://www.worldclim.org/data/worldclim21.html)取得生物气候变量，裁切到研究范围。
3. 删除无坐标的记录，以及落在环境图层缺失区域的点；每个栅格像元仅保留一条出现记录，比较清理前后的分布。
4. 提取出现点所在像元的环境值，用 `dismo` 等工具拟合一个简单的 BIOCLIM 环境轮廓模型。
5. 绘制当前环境下的适宜性图。

## Day 2｜没有可靠的“未出现”记录时怎么办？

1. 分清真正调查过却未发现的**缺失点**、人为构造的**伪缺失点**和从研究范围抽取的**背景点**；理解模型为何需要对照样本。
2. 在选定范围内随机抽取背景点，并让坐标与环境栅格对齐。
3. 整合出现点（标作 1）和背景点（标作 0），提取环境值、去掉缺失值。这里的 0 指背景样本，不能直接解释成“物种确定不存在”。
4. 用逻辑回归拟合广义线性模型（GLM），阅读系数。
5. 用不依赖 Java 的 `maxnet` 拟合 Maxent 模型，并讨论它为何常用于生态学。
6. 画出两个模型的连续预测图并列比较；输出数值的含义还要结合取样设计和模型设置判断。

## Day 3｜筛变量，留测试数据，再评价模型

1. 计算预测变量间的 Pearson 相关，使用 `usdm` 的方差膨胀因子（VIF）检查多重共线性。
2. 将数据分成约 70% 训练集和 30% 测试集，体验样本外预测。
3. 只用训练数据和选定变量重拟合 GLM/Maxent。
4. 在留出的数据上求预测值，认识混淆矩阵和 ROC 曲线，用 `pROC` 计算 AUC，并用 `ggplot2` 作图。
5. 手动遍历 0–1 的阈值：逐个算真正例、假正例、真负例、假负例，观察灵敏度、特异度及真实技巧统计量（TSS）如何变化，并按所选准则挑选阈值。随机拆分表现良好，并不能单凭这一点证明模型可以迁移到新地区。

## Day 4｜把当前模型投到一个假想未来

1. 鉴于课堂上完整 CMIP6 数据体量较大，先用栅格运算构造一个示范情景，例如升温 2°C；这不是经过气候模式评估的未来预报。
2. 将现有模型用于这一情景，比较当前与“未来”环境下的连续适宜性图。
3. 采用 Day 3 的最大 TSS 阈值，将两幅连续图转换为二值图。
4. 用当前值加上未来值的两倍（`current + future * 2`）给稳定、丧失、新增区域编码，再制图。
5. 借助 `data.table` 汇总栅格面积和比例，用 `ggplot2` 绘图。二值化后的“增加/减少”受情景、阈值和模型影响，不能直接当作确定的占域变化。

## Day 5｜给 Maxent 调参

1. 认识特征类别（FC）和正则化倍数（RM）：它们控制响应形状和复杂程度，也影响过拟合风险。
2. 准备出现点、背景点和筛好的环境变量。
3. 使用 `ENMeval` 的空间区块划分（block），讨论为什么空间自相关会使随机 k 折的评价过于乐观。
4. 对线性（L）、线性加二次（LQ）、线性加二次加折线（LQH）等 FC 和 0.5–3.0 等 RM 组合建模；底层用无 Java 依赖的 `maxnet`。
5. 对照评价表，综合 ΔAICc、遗漏率和训练—验证 AUC 差异选择模型，而非只盯住一个最高分。
6. 取出所选模型，绘制调参后的适宜性图。

## Day 6｜换一种取样和验证方式，答案会变多少？

1. 设计三种对比：随机 k 折加广域背景；空间区块加广域背景；空间区块加出现点周围缓冲区背景。同时改变划分方式、背景范围、RM 和 FC。
2. 分别抽取广域背景点，以及出现点周边约 500 km 缓冲范围内的背景点。
3. 分批运行 `ENMeval`，收集各组合的评价指标。
4. 用 `data.table` 汇总，再比较验证 AUC 和 AUC 差异的变化。背景抽样范围和验证划分改变了“模型在回答什么问题”，指标也会随之改变。

## Day 7｜地理地图与环境地图

1. 在地理空间（G-space）比较简单线性模型与更复杂的线性—二次—折线模型，分别绘制连续值和阈值化地图。
2. 提取背景环境值，用主成分分析（PCA）把气候维度压缩成 PC1、PC2，即环境空间（E-space）。
3. 把模型预测为适宜的像元放进环境空间，分别勾画外接矩形、凸包、凹包和最小体积椭圆（MVE）。
4. 在同一张图里显示背景环境、预测点和这四种边界。边界的形状是分析选择，并不自动等于物种的基本生态位边界。

## Day 8｜看懂空间数据和地图投影

1. 认识矢量数据：点、线、面；认识栅格数据：由像元组成的连续表面。尝试栅格化，并注意像元大小限定了表达精度。
2. 区分以经纬度表示的地理坐标系和以平面坐标表示的投影坐标系；经纬度角度不能随意当作平面米数。
3. 比较圆柱投影（如墨卡托，极区形变明显）和圆锥投影（如兰伯特正形圆锥，常用于中纬度）。
4. 从北极出发绘制方位等距投影，理解以中心为基准的距离和方向特性，并用 R、`ggplot2` 重现联合国徽式地图。

## Day 9｜本土和入侵地区的环境占据会变化吗？

1. 分开北美原生区和欧洲入侵区的出现记录，分别界定两地可用的背景环境。
2. 合并两地背景建立共同的环境 PCA，再把两地出现点投到同一坐标系。
3. 用 `ecospat` 在 PCA 空间估计出现密度，计算 Schoener 的生态位重叠指标 $D$，以及稳定、未填充和扩展等指数。
4. 画出密度与背景环境轮廓，判断两地“可用气候不同”和“占据的气候不同”各起了什么作用；谨慎区分统计意义上的环境占据变化与进化机制。

## Day 10｜把时间和空间的尺子拉开

1. 认识不同时间跨度的气候资料示例：Zachos 等的海底同位素记录、EPICA 冰芯和 CMIP6；对比显生宙、上新世—更新世、全新世及近现代气候变化。
2. 用地球半径约 6,371 km 和珠峰约 8.8 km 的尺度对比，想象生物圈有多薄；区分常规 2 m 气象测量、宏气候格网和生物体实际经历的近地微气候。
3. 绘制多面板时间序列和概念性的垂直剖面图。
4. 认识轨道离心率（约 10 万年）、地轴倾角（约 4.1 万年）和岁差（约 2.3 万年），用模拟波形展示它们如何改变太阳辐射条件。课程中的合成曲线属于教学演示，不能当作重建得到的古气候实测序列。

## Day 11｜走出训练环境后，四种算法会怎样反应？

1. 比较参数模型、半参数模型、树模型和最大熵模型的外推方式。
2. 整理丹顶鹤的出现—背景样本，提取 `bio1`（温度）和 `bio12`（降水）。
3. 分别拟合带多项式项的 GLM、`mgcv::gam` 的平滑响应、`randomForest::randomForest` 的随机森林和 `maxnet::maxnet`。
4. 找出训练数据中 `bio1` 的范围，再向范围之外延伸约 ±15°C，同时固定 `bio12` 为样本平均值，构造一个人为的新环境梯度。
5. 用 `data.table` 整理预测，比较模型在边界外截住数值（clamping）或继续急剧变化等表现。这里是在展示算法行为，不能仅凭曲线判断哪一个未来预测为真。

## Day 12｜空间分组为什么会改变验证结果？

1. 从空间自相关说起，考虑随机折、空间独立性、各组样本平衡和迁移目标之间的取舍。
2. 整理丹顶鹤出现点与背景点的坐标、环境图层和研究范围。
3. 英文提纲介绍四种分组：随机四折、按坐标中位数划分的空间区块、单层棋盘格和双层棋盘格。
4. 用 `ggplot2` 在地图上标出样本属于哪一折，以及虚线表示的分组边界。
5. 英文提纲还列出：在四种划分下训练标准化 Maxent，比较验证 AUC 和训练—验证 AUC 差异，并绘制含误差线的柱图。**代码对照提醒：**目前的 [D12.R](D12.R) 实际只计算前三种分组并绘图，没有进行上述模型指标比较；双层棋盘格部分引用了尚未定义的 `cb2_agg`。因此这一天的提纲目标不能直接当作已运行完成的分析结果。

## Day 13｜同一个气候值，在地图和环境空间里怎么看？

1. 比较 WGS84 经纬度、不同中心点的方位等距投影和 Mollweide 等面积投影。
2. 用 `terra` 读取 `bio1`、`bio12` 等栅格，执行重投影，转成 `data.table` 并做标准分数（Z-score）转换。
3. 将地理坐标（X、Y）与环境坐标（Bio1、Bio12）联系起来，用 `sf` 做空间相交或包含查询。
4. 以马来西亚、利比亚、哥伦比亚、中国为例，同时绘制地理分布、当地气候值和全球背景环境，比较不同地区可用的环境组合。

## Day 14｜从出现与否走向计数数据、多算法和规范报告

1. 用 `biomod2` 处理计数响应（`data.type = "count"`）。课程提纲以多年监测数据 DataSTOC 为例，提出用 2006–2011 年校准、2012–2017 年评价，并用 `BIOMOD_FormatingData` 整理数据。
2. 比较深度神经网络（DNN）、梯度提升（GBM）、GLM、多元自适应回归样条（MARS）、随机森林（RF）与 XGBOOST；提纲包括空间区块交叉验证、`bigboss` 参数预设，以及 $R^2$、调整后 $R^2$、均方根误差（RMSE）。
3. 查看变量重要性、校准与验证指标、环境响应曲线和残差或空间异常点（如 `bm_PlotVarImpBoxplot`、`bm_PlotEvalBoxplot`、`bm_PlotResponseCurves`、`bm_ModelAnalysis`）。
4. 用 `BIOMOD_Projection` 投影到两个时期的环境，检查新环境及截断掩膜；课程提纲还列出 `BIOMOD_RangeSize` 以比较时期之间的范围变化。
5. 使用 `BIOMOD_Report` 汇总建模记录，按 ODMAP（Overview、Data、Model、Assessment、Prediction）框架整理报告。计数数据的生态意义取决于调查努力和观测过程，不能仅凭模型标签断定它是无偏的真实种群丰度。

## Day 15｜专家范围图能怎样帮助检查模型？

1. 读懂 IUCN 范围图中的 `PRESENCE`、`SEASONAL` 编码，筛选丹顶鹤的本土繁殖范围；用点落面内检验和缓冲区比较检查记录。
2. 比较 Maxent 线性（L）、二次（Q）、乘积（P）等特征组合，以及不同复杂度下的地图形状。
3. 用 `ENMeval` 对 L、Q、P、LQ、QP 等 FC 和 0.1、1、10 等 RM 进行组合比较，以 AICc 和训练 AUC 等指标审视取舍。
4. 比较全部生物气候变量与只用 `bio1`、`bio12` 的模型，也比较不同背景点数量（如 100 个）对适宜性面的影响。
5. 将多部分多边形拆开，建立凸包，观察其地理中心如何改变。专家范围图也有自己的时间、季节与制图尺度，不能作为所有像元的无误差真值。
