# 课程故事：每画出一张图，就多问一个问题

先想一个具体任务：我们准备到一片新区域调查丹顶鹤，希望用已有记录安排调查路线。此时最想知道的，也许是“哪些环境组合值得优先去看”。如果问题换成“今天哪些地方已经有丹顶鹤”，我们需要的证据就更接近当下的实际占据。两句话都在谈分布，地图却不必相同。

乔慧捷老师的[“没有万能算法”](https://doi.org/10.1111/2041-210X.12397)用模拟物种把这件事讲得很透：作者事先知道潜在适生范围和已占据范围，再让八类算法只凭出现样本去猜。每种方法都曾在某些条件下表现好；换物种、换目标或换评价指标，胜出的模型便可能改变（PDF pp. 2–7）。这给整门课程定下了顺序：**先说清要找的东西，再决定拿什么数据、用什么模型、怎样考试。**

## 1. 出现点是线索，不是完整答案

在 D1，我们先把鸟类记录落到气候格网上。[记录筛选图](figures/story-01-records.png)里，7,239 条记录最后对应 341 个不同的建模像元。像元去重让一个容易到达、反复被观察的地点不至于因为记录多就主导环境关系。

可是地图上大片没有记录的地方，到底意味着什么？可能鸟没去过，可能去了却没人看见，也可能那里根本没被认真调查。D2 于是抽取背景点，让模型知道研究范围里还有哪些气候条件。背景点是**环境对照**。要是把背景范围扩大或缩小，模型看到的对照也会改变。乔老师与合作者研究可达区域时，专门提醒要分清物种实际能接触到的环境和地图上所有可见的环境（[Qiao 等，2017](https://doi.org/10.1038/s41598-017-01313-2)，PDF pp. 2–3）。

## 2. 算法像几种画法，目标决定哪种画法合适

GLM 倾向于用简洁、平滑的曲线表达环境关系。Maxent 从出现点与背景环境的差别入手，可以用线性、二次等特征画出更灵活的曲线。随机森林让许多树分别学习，再汇总它们的判断；boosting 让后面的树接着修正前面的偏差。方法的差异会落到地图上：哪些地方被涂得更深，边缘是否陡峭，训练环境之外的曲线会怎样延伸。

[适宜性地图](figures/story-05-map.png)就是其中一张。深色像元说明，在这一套出现点、背景、气候变量和 Maxent 设置下，模型给了它较高分。把图拿来寻找新的调查地点，可以当作一层线索；要估计真实占据概率，还得把调查与发现鸟的过程放进问题里。

复杂模型常会忠实保留已观测环境里的小空缺。如果我们要描画眼下记录覆盖到的环境，这可能很有价值。如果目标是寻找尚未调查、但鸟可能耐受的环境，填补某些采样空缺也可能更合适。[理论驱动生态位建模框架](https://doi.org/10.59717/j.xinn-life.2025.100165)用图示说明了这两种目标为什么会改变模型选择（PDF pp. 2–4）。这里没有给“简单”或“复杂”预先判胜负；关键是空缺由什么造成，我们想让地图回答哪一句话。

## 3. 考试要像将来的使用场景

D3 的随机留出测试可以告诉我们：在相近的数据范围内，模型能否区分测试出现点和背景点。D5 继续调 Maxent 的复杂度。到了 D6，问题更进一步：如果地图要去新的地点，测试点也应该离训练点远一些吗？

[验证设计图](figures/story-02-validation.png)固定同一组 Maxent 参数，比较三种分组与背景设置。平均训练—验证 AUC 差距从随机方案的 0.036，变为两种空间分组方案的 0.117 和 0.157。读图时要记住，背景范围也跟着变了；我们看到的是**整个验证方案**的差异，不能把变化全归给“分组”一个因素。D12 帮助我们在地图上看这些分组的形状；D6 提供相应的模型数值比较。

考得更难，分数可能下降。这并不自动说明模型没有用，可能是新任务确实更远、更陌生。[Roberts 等](https://doi.org/10.1111/ecog.02881)在空间、时间等结构化数据上说明：验证数据怎样隔开，应当贴近模型最终要面对的新地点、新时期或新个体（PDF pp. 1–3、11–15）。

## 4. 走到新区域，还要看它的环境是否熟悉

课程把两个空间放在一起：**地理空间**问“地图上的哪里”，**环境空间**问“那里的温度、降水等条件是什么”。D7、D9、D13 不断在两者之间来回切换。地理上隔得很远的两地，可以有相近气候；地理上相邻的两点，也可能隔着明显的环境边界。研究原产地与入侵地时，还要分别看当地可供物种接触的环境。乔老师关于[模型转移](https://doi.org/10.1111/ecog.03986)的研究据此检查新区域的环境与训练范围究竟重叠多少（PDF pp. 1、5、7–12）。

D4 用人为设置的气候情景练习重新投影。我们的复现另做了一个清楚指定变量的灵敏度试验：将 `bio8` 增加 2°C，再按 0.25 的阈值给像元分组。[面积变化图](figures/story-04-scenario.png)记录了这次试验中各类别的面积比例。这个练习把“气候值改变—模型重新打分—阈值重新分组”连在一起；它的任务是帮助理解模型响应。D11 则让几种算法面对训练范围以外的温度，直接看它们的外推形状。

## 5. 当回应变量变成计数，比赛规则也变了

D14 不再只问某处是否有记录，而是用 DataSTOC 的一个物种计数示例，比较 GLM、MARS、DNN、GBM、XGBOOST 和 RF。我们的[算法成绩图](figures/story-03-algorithms.png)把训练期与独立后一期的数据放在一起：每种方法的点是四次运行平均值，短线表示一次标准差。图中的得分是观测值与预测值的相关系数平方。

这张图的重点，是让训练成绩和下一时期成绩同时出现。只看前者，可能会错过真正关心的使用场景。这里拟合的是**一个物种的计数**，六种算法各自建模；如果将多个物种通过共同结构一起拟合，才进入联合物种分布模型（JSDM）的问题。

## 读完这门课，带走一个顺序

当有人递给我们一张物种分布图，可以依次问：这张图想找的是当前占据，还是潜在适生？出现记录与背景来自哪里？算法是怎样表达环境关系的？测试数据离训练数据有多远？新区域有没有模型没见过的环境？这些答案会告诉我们，地图适合帮助提出哪一种下一步调查问题。
